# Adversarial-Resilient-Network-IDP-System-using-Deep-learning-with-Real-time-Alerts
Adversarial Network Intrusion Detection System (ANIDS) using CNN-BiLSTM deep learning, FGSM/PGD adversarial robustness, real-time network traffic monitoring with Scapy, adaptive false-positive reduction, and a Flutter-based security dashboard.

#Tools Used for Project Development

| Tool | Purpose |

| Visual Studio Code | Code development and debugging |
| Python | Backend and machine learning development |
| Flutter SDK | Frontend dashboard development |
| Dart | Flutter application development |
| TensorFlow & Keras | CNN-BiLSTM model development |
| Scikit-learn | Data preprocessing and model evaluation |
| Pandas & NumPy | Dataset processing |
| Scapy | Live network packet capture |
| FastAPI | Backend API development |
| Uvicorn | Backend server execution |
| SQLite | Database management |
| Git | Version control |
| GitHub | Project hosting and collaboration |
| UNSW-NB15 | Intrusion detection dataset |
| Swagger UI | API testing |

#Technologies Used
- CNN-BiLSTM Deep Learning
- FGSM & PGD Adversarial Attacks
- Adversarial Training
- Real-Time Network Monitoring
- Network Intrusion Detection
