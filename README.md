# Adversarial-Resilient-Network-IDP-System-using-Deep-learning-with-Real-time-Alerts
Adversarial Network Intrusion Detection System (ANIDS) using CNN-BiLSTM deep learning, FGSM/PGD adversarial robustness, real-time network traffic monitoring with Scapy, adaptive false-positive reduction, and a Flutter-based security dashboard.
